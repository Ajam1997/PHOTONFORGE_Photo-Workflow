    Task 2: Clean Up Notes.md¶

    Files: - Modify: docs/Notes.md

    • [ ] Rewrite docs/Notes.md as a structured Engineering Notes document with two sections:
    • KPM-1.2 Performance Gap — Florence-2 currently 6.7s vs 2.5s target on i7-7500U. Root cause: no KV-cache (using decoder_model for all steps = O(n²)). Investigation path: switch to decoder_with_past_model_int8.onnx but blocked by fixed-16-token input dimension issue.

    • Naming Output Bugs — Two open issues: (a) model outputs one of three strings ("yes" / "no" / "answering does not require reading") instead of real captions; (b) file is not renamed on disk — semantic name written to XMP only, but both the original filename and new name should be stored in XMP and the file should be renamed.

    • [ ] Verify markdown renders cleanly (no escaped underscores, no raw HTML)

    • [ ] Commit: 

      git add docs/Notes.md
git commit -m "docs: clean up Notes.md into structured engineering notes"

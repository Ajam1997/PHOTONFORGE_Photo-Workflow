**Type:** Enhancement (Open)

## Context

FR-1.7.1 (genre back-training) collects user corrections from Darktable tag edits. The correction flow is exposed via CLI commands but needs Lua plugin buttons to be usable from inside Darktable.

## Scope

Add three buttons to the PHOTONForge Lua plugin's panel:

1. **Sync Corrections**
   - Spawns: `photo-workflow correct-genres --photon-db <cartridge>/photonforge.db --darktable-db <cartridge>/darktable/library.db --training-db <cartridge>/training_weights.db`
   - Reads tag edits made by user in Darktable, logs deltas to `training_weights.db.genre_corrections`.
   - Surfaces unknown `photon|genre|*` style tags as candidate new genres in `custom_genres`.

2. **Recalibrate Genre Model**
   - Spawns: `photo-workflow training recalibrate --training-db <cartridge>/training_weights.db`
   - Triggers prototype re-blending + LR adapter retraining.
   - Shows toast with new version + held-out F1.

3. **Promote Custom Genre**
   - Lists rows from `custom_genres` with `n_examples >= 10` and `promoted = 0`.
   - User selects → spawns: `photo-workflow training promote --genre <name> --training-db ...`
   - On confirm, the genre is added to the active GENRES list.

## Acceptance

- All three buttons visible in the PHOTONForge panel
- Each spawns the corresponding CLI command and surfaces stdout/exit code in a Darktable status message
- Long-running commands (recalibrate) show progress, not a frozen UI

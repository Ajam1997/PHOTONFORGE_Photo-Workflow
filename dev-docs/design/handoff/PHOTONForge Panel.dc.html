I · Buildability notes
✓ Tabs, sections, progressive disclosure — real, via stack + buttons, section_label, and visible/sensitive.
✓ Amber accent & status colors — real, via @bauhaus_fill + per-widget name CSS.
≈ Progress bar — approximation. No bar widget; built from a row of fixed box cells recolored by step, plus a label count. Updates discretely, not smoothly.
≈ Per-line log color — approximation. text_view is one flat color. Fallback: keep flat, or prefix lines ([OK]/[ERR]) for scannability.
✗ Thumbnails, ring, stat cards, chips — dream-only. Not in the widget set; live in concept F.
✗ Animated pulse / shimmer — decorative only. GTK transition support is limited; never load-bearing — the dot can simply toggle.
≈ Training-weights inspector — mostly real: version + F1 + per-axis values are labels read from training_weights.db; "View full weights" opens the dump in a text_view. The inline weight bars are the same fixed-box approximation as progress.
✓ Cartridge strip (Archive / Restore / Provision / Eject) — real. Four buttons spawn the backup (archive/restore) + photo-cartridge provision / safe-eject jobs; identity + free space are labels. All four go sensitive=false mid-run.

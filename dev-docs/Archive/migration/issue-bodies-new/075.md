**Type:** Verification fixture (reclassified from type:fr in Phase 4)

**Used by:** KPM-1.6, KPM-1.7, KPM-1.8, KPM-1.10 (labeled reference set for measuring dedup FP rate, naming validity, scoring determinism, and session-grouping precision).

**Location:** `tests/fixtures/` + `corpus/`

## Purpose

A labeled fixture corpus is required for measurable KPMs that need ground-truth comparison:
- KPM-1.6 (dedup false-positive rate) — needs known-distinct image pairs
- KPM-1.7 (naming validity) — needs images with expected non-trivial caption output
- KPM-1.10 (session grouping precision) — needs images with ground-truth session labels

## Specification

Create `tests/fixtures/corpus/` containing:

**Grouping set (~30 images):**
- 3 sessions of ~10 images each
- Session A: timestamps within 30 min of each other, same GPS cluster
- Session B: timestamps 6 hours after A, different GPS
- Session C: timestamps next day
- Ground truth: `tests/fixtures/corpus/grouping_labels.json` — maps filename → session_id

**Dedup set (~20 images):**
- 10 distinct image pairs (visually different, dHash distance >> 2)
- 5 near-duplicate pairs (same scene, slight reframe, dHash distance <= 2)
- Ground truth: `tests/fixtures/corpus/dedup_labels.json` — maps filename → {is_duplicate: bool, pair_id: str}

**Naming set (~20 images):**
- 20 images with diverse content (portraits, landscapes, architecture, abstract)
- Ground truth: `tests/fixtures/corpus/naming_labels.json` — maps filename → {expected_non_trivial: true}
- The label just asserts the caption should NOT be a degenerate string — no specific caption required

## Format

Use synthetic JPEG fixtures (solid colour + embedded EXIF) where possible to keep repo size small. Real-image entries should be Creative Commons licensed with attribution in `tests/fixtures/corpus/SOURCES.md`.

# #78 [Enhancement] Custom tag management UI for Darktable panel
# state: OPEN
# labels: enhancement
---
## Description
Replace the stock Darktable tagging module with a PHOTONForge-specific panel that shows the two axes as dropdowns or button grids, making it easy to assign and correct tags without digging through Darktable's flat tag list.

## Motivation
Current workflow requires navigating through Darktable's flat tag hierarchy, which is cumbersome for the two-axis tagging system (e.g., subject/context or similar dimensional structure). A custom UI would provide:
- Direct visibility of both tag axes
- Quick selection via dropdowns or button grids
- Streamlined tag assignment and correction within the correction loop

## Acceptance Criteria
- [ ] Panel displays two tag axes as separate UI controls (dropdowns or button grids)
- [ ] Users can assign/correct tags without accessing Darktable's stock tagging module
- [ ] Tag changes sync correctly to the Darktable database
- [ ] Integration with the Stage D correction loop workflow
- [ ] User can quickly navigate between images while assigning tags

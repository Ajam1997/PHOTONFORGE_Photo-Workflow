## UN-041 Findings

UN-041 acceptance: "SD card is ejected and the user is notified that photos have been
transferred to the SSD."

The GUI scaffold provides:
- PRESENT: SD card state change is displayed in the StatusBar (sd_mounted false -> "No SD card").
  This is the notification display pathway.
- PRESENT: mount_monitor.rs polls /proc/mounts every 2s and emits device-state-changed events
  that update the status bar indicator in real time.
- ABSENT: No eject command is wired in the Tauri backend (no `umount`, `safe_eject.sh` invocation,
  or Tauri command for ejecting the SD card).
- ABSENT: No explicit user notification dialog/toast is triggered on transfer completion --
  only the passive indicator state change.

Assessment: UN-041 is PARTIAL. The notification display pathway is scaffolded but the active
eject action and a distinct completion notification are not yet implemented. This is expected
for a scaffold stage. Full validation of UN-041 requires Stage 7.x implementation.
